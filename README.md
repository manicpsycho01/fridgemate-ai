FridgeMateAI is an AI-powered smart kitchen assistant that helps users manage their groceries, reduce food waste, and discover recipes using ingredients they already have. By combining intelligent ingredient tracking with AI-generated meal recommendations, FridgeMateAI makes meal planning simple, efficient, and sustainable.

✨ Features
📦 Smart Pantry Management
Add, edit, and remove pantry items.
Organize ingredients by category.
Track quantities and expiry dates.
🤖 AI Recipe Generator
Generate recipes using available ingredients.
Reduce food waste by utilizing items nearing expiration.
Receive creative meal suggestions powered by AI.
🔍 Ingredient Search
Quickly search and filter pantry items.
Easily locate ingredients for meal planning.
📊 User-Friendly Dashboard
View pantry overview at a glance.
Track inventory and ingredient status.
📱 Responsive Interface
